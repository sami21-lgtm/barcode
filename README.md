# Premium Barcode & QR Scanner

A lightweight, high-performance web-based Barcode and QR Code scanner built with HTML, CSS, and Vanilla JavaScript. It features a modern dark-themed Glassmorphism interface, a neon green laser scanning animation, and native device vibration feedback inspired by premium mobile applications.

---

## Features

* **Real-time Scanning:** Fast and accurate detection of both QR codes and standard barcodes.
* **Premium UI:** Glassmorphism card container with a smooth, pulsing neon scanner laser.
* **Auto-Detection:** Stops the camera feed upon a successful scan to prevent duplicate triggers.
* **Haptic Feedback:** Vibrates the mobile device momentarily when a code is registered.
* **Smart Link Redirection:** Automatically parses URLs and displays them as clickable external links.
* **Fully Responsive:** Designed with a mobile-first approach, scaling beautifully on all screen sizes.

---

## Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox, CSS Animations, Backdrop Filters)
* **Logic:** Vanilla JavaScript (ES6)
* **Library:** [Html5-Qrcode](https://github.com/mebjas/html5-qrcode) (via CDN)
